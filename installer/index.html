巴士到站顯示屏 · 安裝工具

ZECTRIX NOTE4（黑白屏）· 版本 —

這個瀏覽器不支援 USB 連接。請用 電腦版 Chrome 或 Edge 開啟此頁（手機、Safari、Firefox 不能使用）。

1連接 NOTE4

用可以傳輸資料的 USB-C 線把 NOTE4 接上電腦，然後按「連接」，在彈出的視窗選擇 USB JTAG/serial debug unit（Mac 是 cu.usbmodem…）再按「連線」。

連接不到？
① 拔走 USB，按住正面的 Home 鍵不放再插上 USB，約 2 秒後放手，再按「連接」。
② 換一條 USB 線或另一個 USB 插口。
③ 關閉其他正在使用 USB 序列埠的程式或分頁。

2備份原廠固件（強烈建議）

把 NOTE4 內現有的全部內容（16MB）存成一個檔案。日後想用回原廠功能，可以用第 4 步還原。 消費版 NOTE4 的原廠固件沒有公開下載，第一次安裝前一定要備份。

3安裝巴士到站固件

會清除 NOTE4 上的所有內容再安裝。完成後螢幕會顯示「設定 Wi-Fi」，跟着螢幕指示用手機設定即可。

已安裝的顯示屏日後更新不用再接電腦：在手機設定頁按「檢查更新」即可，設定會保留。

4還原備份（用回原廠功能）

選擇第 2 步下載的備份檔（大小應為 16,384 KB），把 NOTE4 還原到備份時的狀態。

技術記錄

  
此工具使用 Espressif 的 esptool-js（Apache-2.0），所有操作在你的電腦瀏覽器內進行，備份檔不會上傳到任何地方。
